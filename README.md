# Tierz — installeurs du tracker

Ce dépôt ne contient que les installeurs du tracker Tierz pour Windows, le tracker de statistiques du jeu SPAM.

- **Télécharger la dernière version** : [tierz.gg/telechargement](https://tierz.gg/telechargement)
- Toutes les versions : [Releases](https://github.com/bbt76620/tierz-releases/releases)

Le tracker installé se met à jour tout seul : il n'y a rien à retélécharger ici.

Tierz est un projet de fans, sans lien avec Ticroco. Les cartes et les illustrations de SPAM appartiennent à Ticroco et à leurs artistes.
